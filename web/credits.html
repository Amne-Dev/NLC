Core Technologies

  • Rust — Systems programming language powering the native desktop client.
  • Slint UI — Hardware-accelerated, declarative GUI framework for 60 FPS brutalist desktop design.
  • FastCDC Engine — Rolling hash Content-Defined Chunking for differential updates over HTTP range requests.
  • Python Daemon — Background process supervisor and game orchestration agent.

Third-Party Open Source Libraries

  • minecraft-launcher-lib — Minecraft metadata handling, installation management, and launch argument generation.
  • requests — HTTP networking for Modrinth queries, asset streaming, and differential chunk downloads.
  • Pillow — Image manipulation for skin compositing, texture caching, and dynamic chevron badges.
  • pypresence — Real-time Discord Rich Presence integration.
  • cryptography — Cryptographic verification for update manifests, patch signing, and addon catalogs.
  • skinpy — Skin model parsing and geometry adaptation.
  • pystray — Windows system tray minimization and background daemon control.

Game Ecosystem & External Services

  • authlib-injector — Local skin injection and offline skin servers.
  • Modrinth — Community mod, modpack, and shader discovery.
  • Ely.by — Community authentication and skin services.
  • Microsoft / Xbox — Official Minecraft OAuth authentication.
  • Mod Loaders — Fabric, Forge, NeoForge, and Quilt.
