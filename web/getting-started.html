Getting Started

Last Updated: 2026-04-04

System Requirements

  • Windows 10/11 (x64)
  • Linux x64 desktop with AppImage support
  • Java 17+ (bundled with installer or use system Java)
  • 200 MB free disk for launcher + additional space for Minecraft installations

Installation (Windows)

  1. Download the latest `NLCSetup.exe` from the Releases page.
  2. Run the installer and follow prompts.
  3. Launch the app from the Start Menu or desktop shortcut.

Installation (Linux AppImage)

  1. Download the latest Linux AppImage from the Releases page.
  2. Open a terminal in the folder where the file was downloaded.
  3. Make the AppImage executable:
chmod +x NewLauncher-*-x86_64.AppImage
  1. Run it:
./NewLauncher-*-x86_64.AppImage

If your distro does not open AppImages by double-clicking, launching it from the terminal is enough.

Build on Linux From Source

If you want to build the Linux AppImage yourself from this repository:

chmod +x linux/build_appimage.sh
./linux/build_appimage.sh

The script creates a portable AppImage in the repository root.

First Run

When you first run the launcher, create a profile and select an installation (Latest Release). Configure RAM and Java arguments in Settings if needed.
