Getting Started

Last Updated: 2026-10-29

System Requirements

  • Windows 10/11 (x64)
  • Or Linux x64 desktop with AppImage / FUSE support
  • Basically any computer capable of running Minecraft Java Edition

Installation (Windows)

  1. Download the latest NLCSetup.exe from the Releases page.
  2. Run the installer and follow the prompts.
  3. Launch the app from the Start Menu (Ny-Luna) or desktop shortcut.

Installation (Linux)

1. Universal Quick Install (All Distros)

The recommended method for all Linux distributions. Run this single command in your terminal to automatically install prerequisites (FUSE runtime, desktop icons), download the latest AppImage into /opt/new-launcher, integrate Ny-Luna into your desktop application menu, and register the nlc terminal command:

curl -fsSL https://raw.githubusercontent.com/Amne-Dev/NLC/main/packaging/linux/install.sh | bash

2. Arch Linux, Manjaro & EndeavourOS (PKGBUILD)

To compile and install the native Slint UI package directly using Arch's package manager:

  1. Ensure git and base-devel are installed:
sudo pacman -S --needed base-devel git
  1. Clone the repository and enter the packaging directory:
git clone https://github.com/Amne-Dev/NLC.git
cd NLC/packaging/linux
  1. Build and install the package with makepkg:
makepkg -si

Once finished, launch the app from your application menu or run nlc in the terminal.

3. Ubuntu 22.04 LTS, Debian 12 & Linux Mint (AppImage Setup)

Ubuntu 22.04 LTS, Debian 12 (Bookworm), and Linux Mint rely on libfuse2 to execute AppImages. Follow these steps:

  1. Install the FUSE 2 runtime:
sudo apt update && sudo apt install -y libfuse2 curl
  1. Download the latest release AppImage:
curl -s https://api.github.com/repos/Amne-Dev/NLC/releases/latest \
| grep "browser_download_url.*AppImage" \
| cut -d : -f 2,3 \
| tr -d \" \
| wget -qi -
  1. Make the downloaded AppImage executable and launch:
chmod +x NewLauncher-*-x86_64.AppImage
./NewLauncher-*-x86_64.AppImage

Tip: For automatic desktop menu shortcuts and the nlc command, use the Universal Quick Install.

4. Ubuntu 24.04 LTS & Newer (Noble Numbat FUSE Setup)

Starting with Ubuntu 24.04 LTS, Debian 64-bit transition packages renamed libfuse2 to libfuse2t64. Follow these steps:

  1. Install the modern FUSE 2 transition library:
sudo apt update && sudo apt install -y libfuse2t64 curl
  1. Download the latest release AppImage:
curl -s https://api.github.com/repos/Amne-Dev/NLC/releases/latest \
| grep "browser_download_url.*AppImage" \
| cut -d : -f 2,3 \
| tr -d \" \
| wget -qi -
  1. Make executable and launch:
chmod +x NewLauncher-*-x86_64.AppImage
./NewLauncher-*-x86_64.AppImage

5. Other Distros (Manual AppImage Download)

  1. Visit the official GitHub Releases page and download NewLauncher-*-x86_64.AppImage.
  2. Open your terminal in the directory where the file was saved.
  3. Grant execution permissions:
chmod +x NewLauncher-*-x86_64.AppImage
  1. Run the launcher:
./NewLauncher-*-x86_64.AppImage

The AppImage is fully self-contained and portable with no system-wide installation required.

Build on Linux From Source

If you prefer to build the native Rust frontend and Python backend daemon directly from the source repository:

  1. Clone the repository and install system build dependencies:
git clone https://github.com/Amne-Dev/NLC.git
cd NLC
  1. Make the AppImage builder executable and run it:
chmod +x packaging/linux/build_appimage.sh
./packaging/linux/build_appimage.sh

The compiled NewLauncher-*-x86_64.AppImage will be generated in the repository root directory.

Checksums & Verification

We provide SHA256 checksums for all official installers and AppImages on each GitHub release. After downloading, verify your file integrity before launching:

Windows (PowerShell / Command Prompt)

certutil -hashfile NLCSetup.exe SHA256

Linux (Terminal)

sha256sum NewLauncher-*-x86_64.AppImage

Compare the resulting hash with the SHA256 checksum published on the official GitHub Releases page.

GPG Signatures

When GPG signatures are provided with a release, verify them against the release public key using gpg --verify <signature-file> <binary-file>.

First Run

When you first run Ny-Luna, create a profile (Microsoft, Ely.by, or Offline) and select an installation. Configure RAM and Java arguments in Settings if needed.
