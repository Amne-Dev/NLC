Getting Started

Last Updated: 2026-04-04

System Requirements

  • Windows 10/11 (x64)
  • Or Linux x64 desktop with AppImage / FUSE support
  • Basically any computer capable of running Minecraft Java Edition

Installation (Windows)

  1. Download the latest NLCSetup.exe from the Releases page.
  2. Run the installer and follow the prompts.
  3. Launch the app from the Start Menu (Ny-Luna) or desktop shortcut.

Installation (Linux)

1. Universal Quick Install (All Distros)

Installs prerequisites (FUSE runtime, desktop icons), downloads the AppImage to /opt/new-launcher, adds the Ny-Luna application menu shortcut, and registers the nlc command (with newlauncher alias):

curl -fsSL https://raw.githubusercontent.com/Amne-Dev/NLC/main/packaging/linux/install.sh | bash

2. Arch Linux, Manjaro & EndeavourOS (PKGBUILD)

Build and install the native Slint UI package directly using makepkg:

cd packaging/linux
makepkg -si

3. Ubuntu & Debian (FUSE Setup)

Ubuntu 22.04+ and Debian 12+ require the FUSE 2 runtime to execute AppImages. Install it with:

sudo apt update && sudo apt install -y libfuse2

Note: On Ubuntu 24.04 LTS and newer, use sudo apt install -y libfuse2t64 if libfuse2 is unavailable.

4. Other Distros (Manual AppImage)

  1. Download the latest Linux NewLauncher-*-x86_64.AppImage from the Releases page.
  2. Make it executable and run it directly:
chmod +x NewLauncher-*-x86_64.AppImage
./NewLauncher-*-x86_64.AppImage

Build on Linux From Source

To compile the release binaries and package the self-contained Linux AppImage from this repository:

chmod +x packaging/linux/build_appimage.sh
./packaging/linux/build_appimage.sh

The script creates a portable AppImage in the repository root.

First Run

When you first run Ny-Luna, create a profile (Microsoft, Ely.by, or Offline) and select an installation. Configure RAM and Java arguments in Settings if needed.
