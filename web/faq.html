General & Downloads

Where do I download the official Ny-Luna Core launcher?

Official installers are published directly on our website Download section and GitHub Releases: GitHub Releases.

  • Windows: Download NLCSetup.exe (Web Installer with FastCDC streaming) or NLCSetup-Offline.exe (Standalone Offline Installer).
  • Linux: Download the universal portable AppImage NewLauncher-4.0.4-x86_64.AppImage, run the one-line curl install script, or install via the Arch Linux PKGBUILD / AUR.

Always verify SHA-256 checksums on the Getting Started page before running binaries.

General & Downloads

What are the minimum and recommended system requirements?

Ny-Luna Core is engineered for low resource overhead and native performance:

  • Supported Operating Systems: 64-bit Windows 10/11 or modern Linux desktop distributions (Ubuntu 22.04+, Debian 12+, Arch Linux, Fedora, Manjaro) on x86_64.
  • Memory (RAM): Minimum 2 GB system RAM (recommended 4 to 8 GB allocated for modern modded Minecraft).
  • Disk Space: ~200 MB for launcher runtime plus storage for your instances, modpacks, and game assets.
  • Java Runtime: Java 17 or newer. Ny-Luna automatically detects installed JDKs and seamlessly provisions isolated runtimes as required by different Minecraft versions.
  • Graphics: Dedicated GPU or modern integrated graphics with OpenGL 3.3+ support.

Accounts & Multiplayer

Can I use both official Microsoft accounts and offline accounts?

Yes. Ny-Luna Core offers full flexibility for account management:

  • Microsoft Accounts: Secure OAuth authentication directly with Microsoft's official login service, enabling full multiplayer access on official servers (Hypixel, Mineplex, Realms, etc.).
  • Offline Accounts: Create custom local profiles with custom usernames for singleplayer, LAN multiplayer, and offline-mode community servers without requiring an internet connection.

You can easily switch between multiple accounts directly from the sidebar.

Accounts & Multiplayer

Can I play on official multiplayer servers like Hypixel?

Yes. When logged into an official Microsoft account with a purchased Minecraft: Java Edition license, Ny-Luna establishes standard session authentication tokens identical to the vanilla Minecraft launcher.

You can join Hypixel, 2b2t, private SMPs, Realms, and any public multiplayer server with zero restrictions or authentication errors.

Accounts & Multiplayer

How does Ny-Luna protect my Microsoft account credentials?

Ny-Luna Core takes security seriously. Your account passwords are never seen or stored by the launcher; authentication happens via official Microsoft OAuth tokens.

  • Windows: Tokens and refresh tokens are encrypted using hardware-backed Windows DPAPI (CryptProtectData), tying encryption keys directly to your Windows user logon session.
  • Linux: Tokens are stored in a dedicated local vault encrypted with AES-256-GCM and PBKDF2 key derivation.
  • Zero Cloud Transmission: Authentication tokens are stored strictly on your local disk and are never transmitted to any third-party server or maintainer.
3D Skin Wardrobe

How does offline skin injection work?

Ny-Luna includes an advanced local injection engine. When launching Minecraft, Ny-Luna's backend daemon applies your selected skin, cape, and arm model (Steve 4px or Alex 3px) directly into the game client runtime.

This allows you to play with custom skins on singleplayer worlds, local LAN servers, and offline environments without needing active Mojang authentication servers or third-party skin mods.

3D Skin Wardrobe

Do other players see my custom skin in multiplayer?

Skin visibility depends on the server authentication type:

  • Official Online Servers (e.g. Hypixel): Other players will see the official skin associated with your Mojang/Microsoft profile.
  • Offline Mode / Singleplayer: Your custom skin renders locally for your client across all worlds.
  • Shared Multiplayer Visibility: If playing on private offline servers with friends, standard skin-restorer plugins (like SkinsRestorer or CustomSkinLoader) allow all players to see each other's custom skins.
3D Skin Wardrobe

Can I import standard 64x64, HD, and legacy 64x32 skins?

Yes. The Ny-Luna Wardrobe supports:

  • Standard modern 64x64 PNG dual-layer skins.
  • High-definition 128x128 and HD skin textures.
  • Legacy 64x32 PNG single-layer skins from classic Minecraft versions (automatically converted to dual-layer geometry).
  • Custom Elytra and cape textures.

You can preview your skin with real-time 3D rotation, walking animations, and armor overlays before launching.

Modpacks & Loaders

Which mod loaders are supported?

Ny-Luna Core provides native, out-of-the-box support for all major Minecraft mod loaders:

  • Fabric: Lightweight, modern modding framework with instant loading.
  • Forge: The classic modding standard supporting thousands of complex mods.
  • NeoForge: The next-generation fork of Forge for modern Minecraft versions.
  • Quilt: The community-driven, modular mod loader compatible with Fabric mods.
  • Vanilla: Pure unmodified Minecraft releases, snapshots, and historical legacy versions.
Modpacks & Loaders

Can I install Modrinth modpacks with one click?

Yes! Ny-Luna Core features a deeply integrated Modrinth Browser built directly into the client.

You can search, browse by category (Optimization, Tech, Magic, Adventure), and install complete modpacks (such as Simply Optimized, Fabulously Optimized, or Better MC) with a single click. Dependencies, config files, and loaders are automatically resolved and downloaded.

Modpacks & Loaders

Are my instances, worlds, and modpacks isolated from each other?

Yes. Every profile and modpack runs in a completely sandboxed instance folder:

  • Mods, config files, world saves, screenshots, resource packs, and shader packs are stored separately.
  • Installing a new modpack will never overwrite or corrupt your existing singleplayer worlds or settings from other versions.
Performance & Tech

Why is Ny-Luna so much faster and lighter than other launchers?

Most third-party launchers are built with Electron, Chromium, or bloated web runtimes that consume 300+ MB of RAM just sitting in the background.

Ny-Luna Core is engineered from the ground up with a decoupled architecture:

  • Pure Native Rust Frontend: Powered by the Slint GUI toolkit, rendering hardware-accelerated 60+ FPS graphics with direct GPU shaders.
  • Sub-Millisecond Tab Switching: Zero DOM reflow lag or webview overhead.
  • Ultra-Low Memory Footprint: Uses only ~30 to 50 MB of RAM while running.
  • Clean Teardown: When Minecraft launches, the launcher can automatically minimize, hide to the system tray, or close completely to save 100% of your system resources for the game.
Performance & Tech

What is FastCDC and how do launcher updates work?

FastCDC (Fast Content-Defined Chunking) is our differential update protocol:

Instead of forcing you to re-download 50+ MB binaries on every update, Ny-Luna's update engine analyzes binary file changes at the cryptographic chunk level. When a new version is released, the launcher downloads only the changed blocks (typically less than 2-3 MB), saving bandwidth and updating the client in seconds.

Troubleshooting

The game crashed or won't start — where can I find the crash logs?

Logs and error diagnostics are stored in your user configuration directory:

  • Windows: %APPDATA%\.nlc\logs\ or %LOCALAPPDATA%\NyLuna\logs\
  • Linux: ~/.local/share/nlc/logs/ or ~/.config/nlc/logs/
  • Game Crash Reports: Inside your specific instance folder under instances/<name>/crash-reports/.

You can also view real-time launch logs directly within the launcher under Settings → Console Logs.
